## 概述

本分类当前涵盖 **4 个演示项目技能**，对应上游博客「项目演示」分类的四个独立开源示例工程。它们都是可克隆运行的完整 Vue 3 + Vite 前端项目，覆盖全景联动、地图大屏、LLM 融合与 GeoServer 对接四类典型 Web GIS 场景，适合作为二次开发模板与工程实践参考。

### 何时加载此索引？

- 需要「全景 + 地图」双向联动的实现参考（Photo Sphere Viewer + Leaflet）
- 需要基于天地图的企业级数据可视化大屏工程参考
- 需要 OpenLayers 与 LLM（Dify）结合的智能应用示例
- 需要 vue3-openlayers 声明式组件与 GeoServer REST 图层树对接示例
- 寻找完整的 Vue 3 + Vite 地图类前端工程结构与调试经验
