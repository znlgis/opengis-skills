# MD 规范（魂）

> 本文件是 [../SKILL.md](../SKILL.md) 的参考拆分：MD 载体的六层 schema、逐视图模板与 crosswalk 全文。
> 定位：大模型阅读主线——语义、值、工艺、BOM。文中所有数字均为示例值。

---

## 1. 六层 schema

| 层 | 内容 | 事实源角色 |
|---|---|---|
| 1 元信息 | 图号/版次/比例/图纸方向/提取与渲染参数 | 溯源 |
| 2 布局 | 视图清单与版面布局（r/c 或方位语义）、各视图比例 | 指认入口 |
| 3 逐视图参数几何 | 每视图图元 JSON（带 prim-id，局部 mm 坐标） | 几何可编辑源 |
| 4 标注 | dims 表、气球、焊缝/剖切标记 | 值 |
| 5 BOM | 零件明细（BOM 缺失时见降级规则） | 管理信息 |
| 6 不清项 | unclear 列表：读不清/冲突/待确认 | 诚实记录 |

增补三处（相对基础六层 schema）：**ID 体系、语义注解段、crosswalk 附录**。

元信息层（层 1）建议字段：

| 字段 | 示例值 | 说明 |
|---|---|---|
| 图号/版次 | X600S-888301A 6-3 / R00 | 与 ID 体系绑定，换版即换号 |
| 页面尺寸/方向 | A0 / 竖放 | 页面 pt 尺寸记 W、H（用于换算链） |
| 比例清单 | V15: 1:20 | 每视图比例，供 s 值推导 |
| 提取参数 | DPI≈144、fitz 版本、渲染器及版本 | 保证复跑/换版可复现 |
| 源文件哈希 | — | 追溯"这份交付物对应哪份源 PDF" |

## 2. 逐视图章节模板

````markdown
### V15 吊耳分解详图　(svg: data-view="V15")
- 语义注解：件11吊耳与起吊加固板件10/12/13 的分解形状；件11 为主吊耳 δ30，
  圆头 R150、起吊孔 Ø80；投影关系：与 V01 主视图吊耳位置对应，剖口见 V16。
- 坐标系：原点=视图外形包围盒左下角，X右 Y上，mm。
- 几何图元（带 prim-id）：
  ```json
  [ {"id":"V15-P01","type":"POLYLINE","closed":true,"points":[[0,0],[375,0],...],"note":"件11轮廓"},
    {"id":"V15-P05","type":"ARC","cx":1140,"cy":2850,"r":150,"a1":0,"a2":180,"note":"圆头R150"} ]
  ```
- 尺寸（带 dim-id，与 SVG <text> 同 ID）：
  | dim-id | 值 | 类型 | 关联几何 |
  | V15-D03 | 930 | linear/v | 件10高度方向 |
- 气球：V15-B11→件11 ……　焊缝/剖切：……
````

（示例值：V15、930、R150 等仅为示意。）

模板要点：

- **语义注解段是"理解"的关键增量**：每视图 1–3 句自然语言，写清"看的是什么、投影/剖切关系、关键件功能"，让模型不止会画、还懂意图。
- 图元类型参数化：ARC/OBROUND 等参数图元必须带参数，防止被近似成矩形/六边形。
- dims 表的 dim-id 与 SVG `<text data-dim-id>` 同号；"关联几何"列写"件号 + 方向"。
- 坐标系与 SVG 局部轴定义一致：原点 = 视图 bbox 左下角，X 右 Y 上，单位 mm。

## 3. ID 体系

| ID | 对象 | 示例 |
|---|---|---|
| `V{nn}` | 视图 | V15 |
| `V{nn}-P{mm}` | 几何图元 | V15-P02 |
| `V{nn}-D{mm}` | 尺寸标注 | V15-D03 |
| `V{nn}-B{mm}` | 气球 | V15-B11 |

SVG 与 MD 共用同一 ID 体系；两侧不得各自编号。

## 4. crosswalk 附录

每视图一条，附于 MD 末尾；由脚本同源生成，SVG metadata 内同份，禁手改。

```json
{"view":"V15", "svg_group":"data-view=V15",
 "bbox_portrait_pt":[1890.1,1420.5,2310.7,2260.9],
 "transform":{"s_pt_per_mm":0.14173,
              "rotation":"ccw90",
              "portrait_to_landscape":"(X_L,Y_L)=(y_p, W-x_p), W=2383.654",
              "tx_pt":1420.5,"ty_pt":493.55},
 "local_axes":"原点=视图bbox左下，X右Y上，mm",
 "self_check":"x=0→y_p=1420.5(bbox下界), y=0→x_p=1890.1(bbox左界)"}
```

| 字段 | 含义 |
|---|---|
| `view` / `svg_group` | 视图 ID 与 SVG 组绑定 |
| `bbox_portrait_pt` | 竖放页面 pt 包围盒 |
| `transform` | 换算参数（含义见换算链公式） |
| `self_check` | 自检断言：局部原点必须映射到 bbox 左下角 |

（所有坐标与 s/tx/ty 均为示例值。）

**rotation 唯一结论：** 页面内容回正 = 逆时针 90°（ccw90）；fitz 侧调用 `page.set_rotation(270)`。

## 5. 换算链公式

（x, y）= 视图局部 mm，原点 = 视图 bbox 左下角，X 右 Y 上；s = 2.83465 / 比例分母（pt/mm）：

```
X_L = x·s + tx          Y_L = −y·s + ty
页面 pt（竖放）：x_p = W − Y_L          y_p = X_L
```

示例（V15，1:20 → s≈0.14173）：x=1140, y=2850 → y_p=1582.1, x_p=2294.0，均落于 bbox 内。

## 6. BOM 缺失降级规则

- 当源图标题栏不含可填写的零件明细表时，BOM 章降级为：**记录已识别零件编号（气球清单）+ 标注"BOM 未提供"**。
- 不得臆造材料、重量、数量。
- 已识别零件编号仍按 `V{nn}-B{mm}` 编号入标注层，供指认类验收题使用。

---

## 7. 语义注解段书写规范

- **长度**：最小版每视图 1 句；完整版每视图 1–3 句，另加 1 句投影/剖切关系句。
- **每句覆盖一个维度**：看的是什么（视图内容）、怎么来的（投影/剖切/放大关系）、关键件干什么（功能）。
- **只写语义，不抄数值**：尺寸、角度、材质等值只进 dims 表/BOM，注解段引用它们时用 dim-id/件号指认，避免值与语义双份漂移。
- **必写坐标系声明**：每视图章节开头写"原点=视图外形包围盒左下角，X右 Y上，mm"，与 crosswalk 的 `local_axes` 一致。
